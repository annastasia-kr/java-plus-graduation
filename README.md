# Explore With Me

Приложение-афиша, позволяющее пользователям делиться информацией об интересных событиях и находить компанию для участия в них.

## Архитектура

Проект построен на **микросервисной архитектуре** с использованием Spring Cloud.

## Схема взаимодействия

Внешний API, доступен через Gateway.

> Клиент -> API Gateway (8080) -> Микросервисы

- `Eureka Discovery Server` - регистрация и обнаружение
- `Config Server` - централизованное управление конфигурацией
- `PostgreSQL (5432)` - общий сервер БД

### Инфраструктурные сервисы

| Компонент            | Назначение                               |
|----------------------|------------------------------------------|
| **gateway-server**   | API Gateway на базе Spring Cloud Gateway |
| **discovery-server** | Сервис регистрации и обнаружения (Eureka)|
| **config-server**    | Централизованный сервис конфигурации     |

### Бизнес сервисы

| Сервис              | Описание                                                                    |
|---------------------|-----------------------------------------------------------------------------|
| **event-service**   | Управление событиями, категориями и подборками. БД: `event-db` (PostgreSQL) |
| **user-service**    | Управление пользователями. БД: `user-db` (PostgreSQL)                       |
| **request-service** | Управление запросами на участие в событиях. БД: `request-db` (PostgreSQL)   |
| **stats-service**   | Сервис статистики. БД: `stats-db` (PostgreSQL)                              |

### Общие зависимости

* **`interaction-api`** — библиотека с DTO, Feign‑клиентами и исключениями.
* **`stats-dto`** — DTO для взаимодействий со stats‑сервисом.

### Взаимодействие между сервисами

Микросервисы взаимодействуют между собой через **FeignClient** из модуля `interaction-api`.
- `EventClient` - для вызова методов event-service
- `RequestClient` - для вызова методов request-service
- `UserClient` - для вызова методов user-service

#### Конфигурация
Все настройки сервисов хранятся централизованно в репозитории конфигураций, который обслуживается config-server

> infra/config-server/src/main/resources/config/

### Основные возможности

* **Управление пользователями** — создание, получение, удаление пользователей.
* **Управление категориями** — создание, редактирование, удаление категорий событий.
* **Управление событиями** — создание, редактирование, публикация, поиск событий.
* **Управление запросами** — подача заявок на участие, подтверждение/отклонение заявок.
* **Управление подборками** — создание подборок событий, добавление/удаление событий.
* **Статистика просмотров** — отслеживание количества просмотров событий.

### Запуск

```bash

docker-compose up -d
```
